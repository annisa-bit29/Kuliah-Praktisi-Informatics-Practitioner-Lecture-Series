# Kuliah-Praktisi-Informatics-Practitioner-Lecture-Series
Repositori ini dibuat untuk memenuhi tugas mata kuliah Informatics Practitioner Lecture Series. Berisi kumpulan implementasi kodingan Python dari 6 topik kuliah praktisi bersama para ahli dan praktisi industri/akademisi global.
# Daftar Topik & Implementasi Kodingan
1. Deforestasi AI (`Deforestasi.py`)
   Materi:Attributing Direct Drivers to Deforestation Alerts with Satellite Imagery and AI (Dr. Bart Slachter - Wageningen University & Research).
   Deskripsi:Simulasi ekstraksi fitur citra satelit (Sentinel-2 NDVI & Sentinel-1 Radar) untuk mengklasifikasikan pemicu deforestasi.
2. Human-Computer Interaction (`Human_Computer.py`)
   Materi: Human-Computer Interaction & Data Visualization (Arafat Febrian Dirza, Ph.D. - BRIN).
   Deskripsi:Simulasi pengukuran beban kognitif pengguna (cognitive load) berbasis prinsip User-Centered Design (UCD).
3. Machine Learning (`Machine_Learning.py`)
   Materi: Introduction to Machine Learning (Assoc. Prof. Dr. Taniza Tajudin - UiTM Malaysia).
   Deskripsi: Simulasi sederhana model Supervised Learning (Klasifikasi) dan *Unsupervised Learning* (Clustering).
4. GIS & Analisis Spasial (`gis_analysis.py`)
   Materi: Career and Competition in Industrial Era with GIS (Widi Primadepa - Asset Management GIS Analyst, New Zealand).
   Deskripsi: Simulasi pemrosesan data spasial untuk pemetaan dan *filtering* aset dalam zona risiko bencana.
5. High Performance Computing (`hpc_simulation.py`)
   Materi: Bridging Global Infrastructure to Address Local Challenge with HPC (Dr. Warawan Dias Carbalo - Thammasat University).
   Deskripsi: Simulasi pemrosesan paralel data skala besar untuk mempercepat komputasi lingkungan/iklim.
6. Data Analysis & AI (`data_analysis.py`)
   Materi: Make Sense of Data with Analysis and AI (Andria Arisal, M.Eng. - Senior Researcher BRIN).
   Deskripsi: Simulasi tahapan Data Preparation (pembersihan data kosong) hingga analisis deskriptif dan prediktif.
